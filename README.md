# 🏋️‍♂️ GymBro – Interactive Gym Guide Web App

**GymBro** is a sleek and simple web application built to guide gym enthusiasts through effective workout planning. It features an interactive muscle map that helps users explore exercises by muscle group and provides structured workout splits tailored to different training frequencies.

## 🚀 Features

- 🔍 **Interactive Muscle Diagram** – Hover or click on the human body to explore workouts for specific muscle groups and subparts (e.g., Upper Chest, Rear Delts, Quads).
- 📆 **Workout Splits** – Choose from predefined 3-day, 4-day, 5-day, or 6-day workout routines.
- 🧠 **Fitness Knowledge Hub** – Learn about muscle growth, recovery, and training principles in a simple, beginner-friendly format.
- 🖤 **Clean Monochrome UI** – A distraction-free black-and-white interface focused on utility and clarity.
- 💪 **Detailed Muscle Group Information** – Each muscle is broken down into anatomical and gym-based terms for easy understanding.
